# Frozen H support checkpoint

This checkpoint preserves completed proof sources, their full local import closure, and scoped build, strict axiom, expanded-type, dependency, source/PDF review evidence. It does not register a final H headline or change Root, Audit, STATUS, or passage acceptance.

`source-manifest.json` binds the exact current source bytes and records their direct imports and matching frozen source identities. `artifact-manifest.json` binds completed original packet records. Historical failed fixtures and pending-review prose are retained alongside the later successful receipts and independent reviews; their original status is not rewritten.

The downstream H.3/Corollary 4 proofs retain the precise actual cubic and cutoff pair matrix suppliers. Native H.1 surface support retains its exported almost-every-threshold scope. The I support supplies prerequisite budget, restriction and scalar-kernel proofs; the final Corollary 5 is not accepted here.

Active Gamma, actual-facet, face-reindex, mixed-coarea and ridge-value-continuity work is excluded. `stage-files.txt` is the exact reviewed staging inventory. Run `python3 tools/record_frozen_h_support_checkpoint.py` to regenerate the manifests from the listed frozen packet directories; this script performs no git mutation or Lean proof edit.
